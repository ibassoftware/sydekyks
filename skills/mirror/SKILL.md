# Mirror

Use this skill when the user asks whether vendor bills, credit notes, or payment requests might be
duplicates.

Discover the connected Odoo entities and fields before reading. Read only the bounded evidence
needed: document references, vendor, amount, currency, date, state, and relevant line items.

Screen broadly, then compare plausible pairs in detail. Describe signals and contradictions. A
similar reference or amount is a reason to review, not proof of duplication. Never call a document a
confirmed duplicate without clear evidence, and never delete, post, pay, reconcile, or reverse a
document.

If the user requests a write action, explain the proposed business change and use only the generic
Odoo write tool after the required capability and approval checks.
